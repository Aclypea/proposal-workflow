# 开题报告通用格式规范（中国高校开题报告通用版）

适用于任何学科、任何课题的开题/立项报告写作与模板回填。规则分级：`[强制]` 违反即返工；`[建议]` 写作者酌情处理。

课题专属要求（某导师、某学校、某领域的特殊规定）**不写入本通用规范**，统一登记在课题项目 `config.json` 的 `custom_rules` 中，流水线执行该课题时再叠加生效。

## 1. 标题与章节层级 [强制]

- 顶级标题必须完整呈现，不得丢失或跳级；正文不能从次级标题（如 `1.2.1`）直接开始，必须先有父级标题（`1.1`、`1.2`）。
- 章节编号连续：`1.1 → 1.2 → 1.2.1 → 1.2.2 → 1.3 ……`；方案部分同理（`3.1 → 3.2 → …`）。
- Markdown 标题层级映射：`#` 一级、`##` 二级、`###` 三级，对应 Word Heading1/2/3；同一层级不得混用不同级符号。
- 章节编号规则以学校模板或课题要求为准，默认采用“数字点号”体系。

## 2. 引用角标格式 [强制]

- 正文引用一律使用“作者，年份”圆括号角标：中文作者 `（作者A等，2020）`；外文作者 `（Smith 等，2015）`。
- 两位作者用“和”连接：`（Wang 和 Li，2018）`；多文献并列用分号：`（作者A，2015；Smith，2016）`。
- 禁止 `(Smith, 2013)` 英文逗号式角标；禁止裸写法（只写年份或只写作者）。
- 参考文献表全部条目化，且**正文引用集合 ⊆ 文献表条目**：每条文献必须在正文中被角标提及；未提及的文献不得进入文献表。若学校模板要求“附主要参考文献”可放宽，但仍应尽量收敛。
- 若有学校统一的引文规范（顺序编码 [1]、著者-出版年、脚注等），**以其为准**，并在课题配置中注明。

## 3. 研究现状写作边界 [强制]

- 研究现状只写**国内外已有研究、发展动态、方法与结论的综述**，按主题组织小节。
- **禁止**在研究现状中穿插本课题的设计思考、方案选择、风险判断或“本研究拟……”等自我论证；课题思考放到“研究背景与意义”或“研究内容”部分。
- 每段以具体文献为主语或依据，避免空泛“有研究显示”“相关研究较多”。

## 4. 专有名词与术语格式 [强制]

- 首次出现的专有名词采用“中文全称（英文全称，缩写）”或“中文全称（英文全称）”：
  - 例：扫描电子显微镜（scanning electron microscope，SEM）；主成分分析（principal component analysis，PCA）。
- 同一名词再次出现只使用中文名或缩写。
- 学名（属、种、拉学名）用斜体，如 `*Apis mellifera*`。
- 英文单词与中文之间保留空格（如“Smith 等”），缩写直接书写。
- 术语选择遵循学科惯例与学校/学院规范；特殊用词偏好（如禁用某词、必用某词）写入课题配置 `custom_rules`，不写进通用规范。

## 5. 用词与表述纪律 [强制]

- 禁用绝对化表述：“首次”“填补空白”“开创”“证明因果”等，除非有明确证据与文献支撑。
- 弱结论必须保留边界：“尚不能”“不能由……充分解释”“作为探索性/次级分析”。
- 不虚构任何内容：设备型号、合作单位、经费、数据、DOI、日期、人名，均以事实为准；无法确认的信息如实留待作者填写。
- 不自动升级事实：不得把“may indicate”扩写为“proves”，不得把观察性结果写成因果结论。

## 6. 章节顺序与实验/研究流程一致性 [强制]

- 章节编排应与研究执行流程一致：研究方案中的小节顺序 = 实际执行顺序；先开展的结构描述/测量在前，破坏性制样（镀膜、包埋、消解等）在后。
- 若研究包含多项测量技术，遵循“先无损伤、后破坏性”的通用原则；涉及具体仪器先后顺序的领域惯例，写入课题 `custom_rules`。
- 每个实验/方法小节明确“本步骤目的、关键质控参数、无效数据的判定与保留”。

## 7. 篇幅与交付规模 [强制]

- 正文字数按学校要求（常见 1.5万—2.5万）；超出或不足在正文主体（不含文献与固定表格）校准。
- 参考文献数量不低于学校底线（常见 ≥50—70 条），且全部经过核验分级（A/B/C 级 provenance：A=已联网核验，B=原稿支持待复核，C=新增待复核）。
- 交付物成套：Word（模板回填版）＋ PDF（渲染验收）＋ Markdown 归档 ＋ 参考文献库 ＋ 统计方案 ＋ QA 报告 ＋ 声明—证据表。

## 8. 模板回填注意事项 [强制]

- 源模板只读；回填时复制副本；固定表格（封面、个人信息、审核意见、成绩单、计划表等）原样保留，不重排、不删除。
- 回填后必须验证：新标题出现、旧标题消失、各章节完整、文献条目数准确、固定表格仍在。
- Word 导出 PDF 前确保 `TEMP/TMP` 与 Office 缓存目录可写（`C:\Users\<user>\AppData\Local\Temp`、`INetCache\Content.Word`、`Content.MSO`），否则 Word 报“检查临时环境变量”。

## 9. 统计与实证边界 [强制]

- 明确“独立重复单元”与“技术重复”：观测单元（个体/样本/地块）为独立重复；同一观测单元内的多次测量（脉冲、点位、图像重复）为技术重复，不得当作独立样本放大样本量。
- 数据层级与重复结构在统计方案中预先声明：重复性指标（如 ICC/CV）、混合效应模型、递进模型比较（基础模型 → 加第一组变量 → 再加第二组变量）、多变量降维与关联分析（PCA/RDA/PLSR 等）、路径模型/结构方程（样本不足时只用简化或分段形式）、分类/预测（作为次级分析，交叉验证按独立重复分层且预处理在训练折内完成）。
- 具体统计方法与模型结构因课题而异；统计方案在数据收集前冻结，随机种子与软件版本全程记录以保证可复现。

## 10. 课题自定义规则（custom_rules） [强制]

每个课题的 `config.json` 可登记 `custom_rules`（数组或对象），内容为该课题特有的硬性要求，示例：

```json
"custom_rules": [
  "术语：某两个近义词中统一使用A，不用B（示例，按课题实际填写）",
  "实验顺序：X类测量必须排在Y类制样之前（示例，按课题实际填写）",
  "引用规范：采用顺序编码制 [1]（示例，按课题实际填写）"
]
```

流水线执行该课题时，通用规范 + `custom_rules` 叠加生效；`custom_rules` 与该课题银河冲突时以 `custom_rules` 为准。课题结束后，若某项规则被证明对多数课题亦有价值，再评估是否提升为通用规范。
