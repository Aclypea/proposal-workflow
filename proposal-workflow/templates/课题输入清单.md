# 课题输入清单（proposal_input_checklist）

每个新课题在阶段 0 使用本清单采集信息。逐项填写后生成 `<project>/out/config.json` 与 `00_scope.md`。**没有信息的项就留空或标注“待导师确认”**，绝不编造。

## 1. 基本信息

| 项 | 填写 |
|---|---|
| 课题题目（锁定版） |  |
| 学科 / 研究领域 |  |
| 学位层次（硕士/博士）与学校 |  |
| 学院 / 专业方向 |  |
| 学生姓名 / 学号 / 导师 | （回填模板用，缺则留空） |

## 2. 学校的开题报告要求

| 项 | 填写 |
|---|---|
| 学校 Word 模板文件路径 |  |
| 模板章节锚点（一、立题依据 … 六、…） | 无则用默认六段 |
| 模板中的旧题目（需替换的） |  |
| 目标正文字数 |  |
| 参考文献数量底线 |  |
| 上交 / 开题日期 |  |
| 是否有统一引文规范（顺序编码/著者-出版年/脚注） |  |

## 3. 课题本身

| 项 | 填写 |
|---|---|
| 研究背景（2—5 句） |  |
| 拟解决的科学问题（1—3 个） |  |
| 研究目标（本次开题要写明的） |  |
| 主要研究内容（各模块） |  |
| 研究方法 / 实验设计 / 主要仪器 |  |
| 数据特点（是否多层/重复测量/时序等；独立重复单元是什么） |  |
| 可行性依据（现有基础、设备、经费） |  |
| 创新点候选 |  |

## 4. 文献材料（可选）

> 没有文献材料也能开工：只填题目/思路即可，Agent 会自我联网检索并核验文献（Crossref/OpenAlex/PubMed 等）后建库。若你的 AI 工具无联网能力，它会列出需要你补充的文献清单。

| 项 | 填写 |
|---|---|
| 用户提供的材料（原开题、文献列表、PDF、笔记路径；无则留空） |  |
| 领域核心文献 / 团队代表作（有则提供，可加速） |  |
| 希望引用的中文/英文期刊偏好 |  |
| 建议排除的文献（如未核验预印本） |  |

## 5. 课题自定义规则（custom_rules）

每条一行，示例：

```json
"custom_rules": [
  "术语：某两个近义词中统一使用A，不用B（示例，按课题实际填写）",
  "实验顺序：X类测量必须排在Y类制样之前（示例，按课题实际填写）",
  "引用规范：采用顺序编码制 [1]（示例，按课题实际填写）",
  "研究现状小节命名：……（示例，按课题实际填写）"
]
```

> 说明：这些规则只在该课题生效并写入其 config.json；**不**进通用格式规范。若日后被证明对多数课题有价值，再提升为通用规则。

| 是否要 PDF 渲染 / 统计方案 / 参考文献核验报告 | 默认全套 |
| 其他特别说明 |  |

## 使用方式

1. 复制本文件到 `sources/课题输入清单.md`；
2. 与用户逐项确认（或用户直接填写）；
3. 由输入生成 `out/config.json`（含 `heading_anchor`、`old_title`、`section_files`、`custom_rules`）；
4. 进入流水线阶段 1。
