# 开题报告项目配置文件模板（proposal_project_config）

新课题在阶段 0 复制本文件为 `<project>/out/config.json`，按实际修改后交给构建脚本。字段均可省略，省略时用脚本内置默认值。

```json
{
  "old_title": "旧题目全文（必须与模板中一字不差；找不到时脚本自动跳过标题替换）",
  "heading_anchor": [
    "一、立题依据",
    "二、研究内容和目标",
    "三、研究方案设计及可行性分析",
    "四、本研究课题的特色与创新之处",
    "五、研究基础与工作条件",
    "六、研究工作计划及预期研究结果"
  ],
  "section_title_regex": "^\\d+_",
  "keep_sixth_table": true,
  "section_files": [
    ["01_立题依据_研究背景与意义.md"],
    ["02_立题依据_国内外研究现状.md"],
    ["03_研究内容和目标.md"],
    ["04_研究方案设计及可行性分析.md"],
    ["05_创新点与研究基础.md"],
    null
  ],
  "custom_rules": [
    "术语：某两个近义词中统一使用A，不用B（示例，按课题实际填写）",
    "实验顺序：X类测量必须排在Y类制样之前（示例，按课题实际填写）"
  ]
}
```

## 字段说明

| 字段 | 含义 | 默认值 |
|---|---|---|
| `old_title` | 模板中待替换的旧题目 | 空字符串（自动定位“论文题目”后的首个文本） |
| `heading_anchor` | 模板固定章节标题数组，构建器按顺序依次定位 | 常见开题六段 |
| `section_title_regex` | 分节文件名前缀匹配，用于按序对应六段 | `^\\d+_` |
| `keep_sixth_table` | 第六部分是否保留模板“时间—研究内容—预期结果”三列表格 | `true` |
| `section_files` | 每段对应的分节文件（可多文件/可空），支持 `file.md#章节标题` 拆分语法 | 自动按文件名匹配 |
| `custom_rules` | 课题特有规则（术语、顺序、引用规范等），写正文与 QA 时叠加生效 | 空数组 |

## 不同学校模板的适配

- 章节锚点文本不同：改 `heading_anchor`；
- 论文题目字段非“论文题目”：脚本回退逻辑定位失败时，把含题目的单元格锚点写进 config 的 `old_title` 直接全文替换；
- 不需要旧标题替换：`old_title` 留空且不传 `-NewTitle`；
- 第六部分无表格（纯文本）：设 `keep_sixth_table=false`，并把第六部分分节文件作为第 6 个文件回填。

## 分节文件命名约定

`drafts/sections/` 下按执行顺序命名（文件名前缀不影响内容，仅用于排序与对应锚点）：

```
01_立题依据_研究背景与意义.md
02_立题依据_国内外研究现状.md
03_研究内容和目标.md
04_研究方案设计及可行性分析.md
05_创新点与研究基础.md
06_研究工作计划及预期研究结果.md
```

若某个学校模板的段落与标准结构不同，用 `heading_anchor` 对应 + `section_files` 显式指定文件归属（支持一段多文件与一个文件拆多段）。

标题格式遵守 `references/开题报告格式铁律.md` §1（完整层级、编号连续）。
