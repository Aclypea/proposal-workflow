# 演示走查（demo-runbook）— 虚构课题

> 本文件完全脱敏：课题、数据、学校均为虚构，仅用于演示"工作流怎么把一个课题跑成成套开题报告"。收到包后，请仿照本走查处理你自己的课题。

## 虚构课题设定

- 题目：基于多源遥感影像的亚热带山地常绿阔叶林树种多样性监测方法研究
- 学科：生态学 / 森林遥感
- 学位：硕士（某大学林业与资源环境学院，模板为该校开题报告 docx）
- 学校要求：正文约 1.8 万字，参考文献 ≥ 70 条，七个模板章节
- 文献材料：用户提供 2 篇综述 PDF、1 份文献列表、若干数据草稿

## 阶段 1：证据底座五文件

- `01_research_canon.md` — 硬事实：Landsat/哨兵系列分辨率、光谱指数种类、森林样地调查规范等（全部写清来源）；禁忌：不虚构精度指标、不引用未核验预印本。
- `02_evidence_table.md` — 声明→证据（C001 多光谱指数可表征树种组成 → 引综述 A；C002 样地调查是多样性监测基准 → 引规范文献）。
- `03_argument_map.md` — 张力：大范围遥感 vs 亚热带高异质性 → 问题是"多源+尺度策略能否提升树种多样性估计精度" → 论点 → 备选（单源/单一尺度）→ 零结果价值（若未提升，界定适用边界仍有价值）。
- `04_section_contracts.md` — 每节 purpose / allowed / forbidden / 验收。
- `05_style_guide.md` — 术语表（光谱指数、异质性、冠层结构等）、引用规范、禁用词。

## 阶段 2：文献检索与核验

- 候选库建到 78 条（遥感树种识别、光谱指数、机器学习分类、样地设计、尺度效应、不确定性）。
- 核心 15 条用 Crossref/OpenAlex 逐字段核验：作者、标题、年份、卷期页、DOI。
- 分级：A=12、B=30、C=36；未核验预印本 2 条排除。
- 输出 `literature/reference_library_78.md` + `qa_logs/reference_verification_report.md`。

### 阶段 2 的分支 B 演示（无文献材料）

若用户只给题目/思路、未提供文献，则改为：

1. Agent 依据课题主题自行联网检索（Crossref / OpenAlex / PubMed 等，按学科选择）；
2. 检索策略：主题关键词组合 → 综述优先 → 近 10 年高被引与最新 → 补经典方法学文献；
3. 每条取自检索源的元数据（作者、年份、标题、期刊、卷期页、DOI），逐条核验并 A/B/C 分级；
4. 未核验预印本、出处不明条目不入库；数量不足时扩词扩域补检；
5. `reference_verification_report.md` 中每条标注"Agent 检索来源"与核验级别；
6. 若 Agent 无联网能力，改为向用户开列"需补充文献清单"后等待提供。

## 阶段 3：分节正文（drafts/sections/）

按章节合同写 01—06 六个 md；每节后 `writing_audit`，合并 `proposal_v0.md` 后全文审计。

- 01 研究背景与意义：亚热带山地高异质性与监测需求；遥感树种多样性监测的价值与缺口。
- 02 国内外研究现状：光谱/结构指数、机器学习与深度学习分类、多源协同、尺度效应、样地基准——每段以文献为主语，不穿插课题设计。
- 03 研究内容和目标：内容（多源数据构建、模型比较、尺度策略、验证）；目标（定量指标）；拟解决问题。
- 04 研究方案：数据获取 → 样地设计（独立重复=样地）→ 影像处理 → 特征提取（光谱、纹理、地形）→ 模型（RF/LDA 次级；递进模型）→ 尺度聚合策略；章节顺序=执行顺序。
- 05 创新点与研究基础：不夸大（"首次"禁用，写"将多源+尺度策略系统比较"）；已有基础、仪器条件、待确认项。
- 06 研究计划：时间安排表 + 预期结果（含零结果定位，如"若未提升精度，则界定适用边界并提供误差来源诊断"）。

## 阶段 4：统计方案（统计方案在数据收集前冻结）

- 独立重复=样地；同一样地内多次像元/样方测量=技术重复，不得放大样本量。
- 随机化/区组：样地按海拔坡向分层；影像批次入模。
- 重复性：特征提取重复（ICC/CV）。
- 递进模型：M0 地形+气候 → M1 + 单源指数 → M2 + 多源指数；AIC/AICc/BIC + 空间交叉验证 RMSE。
- 多变量：PCA 描述共变；PLSR 处理高共线；RDA 关联响应。
- 分类（RF/LDA）为次级：分区交叉验证、预处理在训练折内、报告 balanced accuracy 与置换基线。
- 缺失与无效像元：预设规则、保留审计日志；随机种子与包版本记录。
